# Flashcards

An Anki deck of every term in the course glossary (one card per term: term → meaning, with the lessons that teach
it). Generated by `tools/build_glossary.py` from the lessons' Key-terms tables.

| File | Use |
|:--|:--|
| `fundamental-investing-glossary.apkg` | Anki: *File → Import*, pick the file. Re-importing an updated deck updates cards in place (stable IDs) |
| `fundamental-investing-glossary.tsv` | Plain-text import into Anki (tab-separated; column 3 = tags) or any other flashcard app |

Tags follow the lessons (`fi::02_1` = lesson 02.1, `fi::I4` = India case 4), so you can study one module at a
time with a filtered deck such as `tag:fi::06_*`.

Suggested routine ([00.2](../docs/00-orientation/02-how-to-use-this-course.md)): new cards for each module as you
finish it, 20 new cards a day at most, reviews daily.
