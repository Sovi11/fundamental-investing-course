# Module 02 · Accounting Foundations

**What this module does.** Teaches the language every later module speaks: the accounting equation, accrual
accounting and revenue recognition, the three statements line by line, how they link, and the deeper cuts —
inventory, depreciation, capitalisation, leases, consolidation, deferred tax, provisions, share-based payments —
plus the Ind AS / IFRS / US GAAP differences an analyst meets. Kaveri Pumps' FY26 statements are annotated in full.

**Why it matters.** Ratios, valuation and forensics are arithmetic on these statements. If you do not know what a
line contains, how it was measured and what choice produced it, every later number is a guess.
