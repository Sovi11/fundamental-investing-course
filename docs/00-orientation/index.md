# Module 00 · Orientation

**What this module does.** Sets the frame for everything that follows: what fundamental investing is (and
what it is not), how to use the course and its tools, and a preview of the destination — a finished one-page
thesis — so that the accounting and analysis modules never feel like theory for its own sake.

**Why it matters.** Most people who "learn investing" learn techniques without a model of where edge comes
from. Lesson 00.1 gives that model; 00.2 gives the study plan; 00.3 shows the whole workflow on Kaveri Pumps
before you know how any step is done, so you know why each later module exists.
