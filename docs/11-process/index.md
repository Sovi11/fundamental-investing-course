# Module 11 · Investment Process & Portfolio Management

**What this module does.** Assembles the analysis into a repeatable process: idea generation (screens, events,
insiders, a circle of competence), a stage-gated research process, the investment memo (with a complete sample on
Kaveri), position sizing and portfolio construction (Kelly, max-loss, liquidity, concentration, cash), monitoring
and selling (with the current Indian tax rules), behavioural finance and decision journals, and — for
option-literate investors — expressing fundamental views with derivatives inside Indian F&O rules.

**Why it matters.** Analysis without process produces occasional insights and frequent losses. Process is what
makes results repeatable and reviewable — and what a personal research operation (the private casebook) runs on.

## You're ready to move on when you can…

- [ ] Run a screen, an event scan and an insider check, and log the ideas with sources and kill criteria.
- [ ] Execute a 30-minute kill test and a 3-hour triage on any idea.
- [ ] Write a one-page memo with a variant perception, valuation distribution, catalysts, pre-mortem and dated
      thesis-breakers.
- [ ] Size a position with fractional Kelly and the max-loss rule, apply liquidity and governance overlays, and
      audit the portfolio's thesis-variable concentration.
- [ ] Run a quarterly review, apply the four sell reasons, and compute the tax on a sale.
- [ ] Keep a decision journal with confidence levels and grade process separately from outcome.
- [ ] Map a fundamental view to an option structure and state the Indian F&O constraints.
